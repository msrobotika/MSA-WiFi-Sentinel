# Security policy

Report a vulnerability through GitHub **Security advisories → Report a vulnerability**. Avoid publishing device identifiers, nearby SSIDs/BSSIDs, private captures, or credentials in an issue.

MSA WiFi Sentinel is a passive teaching and diagnostic instrument. It does not associate with a Wi-Fi network, request passwords, inject frames, deauthenticate clients, or prove that an attack occurred. Its warnings are observations that require human verification.

Only observe radio traffic where local law and your authorization allow it. Before sharing screenshots or exports, remove identifiers belonging to nearby networks.
